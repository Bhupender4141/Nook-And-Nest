# Nook & Nest — Home Décor E-commerce Demo

A responsive front-end e-commerce website concept for a fictional home décor brand. Built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Responsive landing page and product grid
- Product search, category filters, and sorting
- Add-to-bag interactions, quantity controls, remove item, and subtotal
- Cart persists in browser `localStorage`
- Newsletter form demo feedback
- Accessible labels, keyboard Escape-to-close, reduced-motion support
- Custom CSS product illustrations — no product image downloads required

## Project files
- `index.html` — page structure
- `style.css` — responsive layout and visual styling
- `app.js` — product data and interactive behaviour
- `TESTING.md` — manual test checklist
- `.gitignore` — common files to exclude from Git

## Run locally
1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a modern browser. For the best development workflow, use VS Code with the Live Server extension.
4. No build step or package installation is required.

## Publish with GitHub Pages
1. Create a new public repository named `nook-and-nest`.
2. Upload the *contents* of this folder to the repository root (not only the ZIP file).
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important demo notes
- This is a portfolio/student demo, not a production store.
- Checkout is intentionally a demo message. No payment is processed and no order is placed.
- Newsletter signup does not send or store email addresses.
- Product ratings and product catalogue are sample content.
- Cart data is stored only in the visitor's own browser.
